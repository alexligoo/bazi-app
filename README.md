# 八字排盘 (BaZi App)

一款基于 Flutter 开发的专业八字排盘应用，融合了传统中华文化设计风格与现代智能交互体验。

## ✨ 核心功能

1.  **智能语义识别**
    *   支持自然语言输入生辰信息，例如：“李四 1995年农历八月十五 晚上8点出生 男”。
    *   自动解析姓名、性别、公历/农历日期、模糊时间段（如“早子时”、“晚子时”）。

2.  **专业八字排盘**
    *   **四柱八字**：精确计算年、月、日、时四柱干支。
    *   **神煞纳音**：包含十神（比肩、伤官等）、藏干、纳音五行分析。
    *   **大运推算**：根据性别与年干阴阳推算起运年龄及大运排布。
    *   **节气计算**：内置高精度天文算法计算二十四节气，精准定月令。

3.  **数据管理**
    *   **本地存储**：使用 Hive 数据库离线存储排盘记录，保护隐私。
    *   **历史回顾**：支持按时间排序查看历史记录，支持收藏重要命盘。

4.  **精美 UI 设计**
    *   **水墨画风**：采用宣纸色背景（#F8F0E5）与深褐色（#5C4033）文字，还原传统纸质书写体验。
    *   **优雅交互**：iOS/Android 双端适配，流畅的动画效果。

5.  **辅助功能**
    *   **图片导出**：支持将排盘结果保存为图片至系统相册（需相关权限）。

## 🛠️ 技术栈

*   **框架**: Flutter 3.x
*   **语言**: Dart
*   **存储**: Hive (NoSQL Key-Value Database)
*   **工具**: `image_gallery_saver` (图片保存), `uuid` (唯一ID生成)

## 🚀 快速开始

### 环境要求
*   Flutter SDK >= 3.0.0
*   Dart SDK >= 3.0.0
*   Android Studio / Xcode (用于模拟器或真机调试)

### 安装步骤
1.  **克隆项目**
    ```bash
    git clone https://github.com/your-repo/bazi_app.git
    cd bazi_app
    ```

2.  **安装依赖**
    ```bash
    flutter pub get
    ```

3.  **运行项目**
    ```bash
    flutter run
    ```

## 📦 打包构建 (Android)

本项目提供了一键打包脚本，自动处理签名密钥生成与 APK 构建。

### 自动打包
直接运行根目录下的脚本：
```bash
sh build_apk.sh
```
脚本会自动检查并生成 `key.properties` 和签名文件（如果不存在），然后构建 Release 版 APK。

### 手动打包
1.  确保 `android/key.properties` 配置正确。
2.  运行构建命令：
    ```bash
    flutter build apk --release
    ```

构建产物路径：`build/app/outputs/flutter-apk/app-release.apk`

## 📖 使用指南

对于**智能输入框**，您可以尝试以下输入格式：
*   标准格式：`张三 1990年1月1日 12:30 男`
*   农历格式：`李四 1995年腊月初八 辰时 女`
*   模糊时间：`王五 20000101 早上8点`
*   纯数字：`199808081200` (年份日期时间)
